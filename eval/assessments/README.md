# Оценки по модел

Една оценка на прогон. Името на файла носи модела, а таблицата в началото на всеки
файл фиксира точно срещу какво е тествано: модел, доставчик, reasoning effort,
идентификатор на прогона, извадка, SHA-256 на промпта и на набора, параметри и кой
е оценявал.

Сравнение между два реда има смисъл само когато промптът, наборът, извадката и
параметрите съвпадат. Различен reasoning effort означава, че моделът не е единствената
променлива.

преглед и не установява терапевтичен ефект. Докато оценителят знае кой модел гледа,
разликата между два реда съдържа и пристрастност на оценителя, не само разлика между
моделите.
